# doksam Ember Bloom — 디자인 스펙

작성일: 2026-07-13
상태: 승인 대기 → 구현 예정

## 1. 개요

`doksam-ember` 확장에 4번째 테마 **doksam Ember Bloom**을 추가한다.
기존 3종(Ember / Ember Light / Ember Dark)의 warm earthy 정체성을 유지하되,
살구빛 파스텔 캔버스 위에 채도를 올린 syntax·아이콘·악센트를 얹어
"밝고 화사하지만 코드와 UI 요소가 또렷하게 도드라지는" 라이트 테마를 만든다.

- 컨셉: *"살구빛 파스텔 캔버스 위에 선명하게 피어난 코드"*
- `uiTheme`: `vs` (라이트)
- 형제 테마의 4번째. 브랜드 일관성 유지.

## 2. 목표 / 비목표

**목표**
- 부드럽고 따뜻한 파스텔 배경으로 화사한 분위기.
- 배경보다 채도를 확실히 올린 syntax로 코드 가독성·대비 확보.
- 악센트(커서/탭/뱃지/아이콘)를 기존보다 진하게 해서 UI 요소가 도드라짐.
- 기존 테마 파일과 동일한 키 구조·완성도(터미널 ANSI, 괄호쌍 6색, git 장식, 시맨틱 하이라이팅) 유지.

**비목표**
- warm ember 색계열을 벗어난 새 색상 체계(쿨톤/멀티 레인보우) 도입 안 함.
- 기존 3개 테마 색상 변경 안 함.
- 확장 로직/빌드 파이프라인 변경 없음(순수 테마 JSON + `package.json` contributes 항목 추가).

## 4. 구현

### 4.1 파일

- 신규: `themes/doksam-ember-bloom-color-theme.json`
  - 기존 `themes/doksam-ember-light-color-theme.json`을 구조 템플릿으로 삼아 전체 키를 채운다
    (colors 워크벤치 전 영역 + tokenColors + semanticTokenColors + 터미널 ANSI 16색 + 괄호쌍 6색 + git 장식).
  - `"name": "doksam Ember Bloom"`, `"type": "light"`.
- 수정: `package.json` — `contributes.themes` 배열에 항목 1개 추가:
  ```json
  {
    "label": "doksam Ember Bloom",
    "uiTheme": "vs",
    "path": "./themes/doksam-ember-bloom-color-theme.json"
  }
  ```
- 수정: `package.json` `version` → `0.5.0` (마이너 — 신규 테마 추가).
- 수정: `README.md` — 테마 표에 Bloom 행 추가, 필요 시 팔레트 섹션 보강.

### 4.2 완성도 체크리스트 (기존 테마와 동일 수준)

- [ ] 워크벤치 colors: 에디터/사이드바/패널/탭/상태바/터미널/알림/git 등 기존 light 테마가 정의한 모든 키 존재.

- [ ] 괄호쌍 6색.
- [ ] git 장식 색(추가/수정/삭제/미추적).
